# Proyect #71
## Proyecto Intermodular 1º SMR 2026
### Autor: Francisco Javier Moreno Juárez
En este proyecto se abarca desde las asignatura de 1º de sistemas microinformáticos y redes la infraestructura informática de un equipo de competición de moticilismo amateur.
En el proyecto se da forma a un equipo de cinco personas con bajo presupuesto. En el cual se da solución a las necesidades informáticas del equipo, desde el hardware hasta el software incluyendo las redes.
Este proyecto está separado por asignatura, cada una con su README y su documentación.
