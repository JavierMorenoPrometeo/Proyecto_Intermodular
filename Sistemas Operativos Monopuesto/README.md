# Proyect #71
## Autor: Francisco Javier Moreno Júarez
Para el sistema operativo se ha elegido Windows 11 por su facilidad de uso y soporte.

Se ha optado por su versión Windows 11 Pro, el uso que vamos a dar a los ordenadores es a nivel usuario en su mayoría, por lo cual no necesitamos una versión más pretenciosa.

Configuraremos las copias de seguridad automáticas y contaremos con el NAS para tener una copía de todo guardada en él. Tendremos además, el firewall activo y las actualizaciones del sistema al día.

Instalamos el software mínimo necesario para nuestras tareas, optimizando así el espacio.
